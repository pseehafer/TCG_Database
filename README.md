# TCGDatabase
Personal project to organize and create an inventory for personal Pokemon, MTG, and other TCG cards.

## Functionality
### User Friendly UI
Will include a user friendly UI system that will help streamline productivity to be able to find cards quicker.

### Spreadsheet Import
A spreadsheet import functionality that will help with adding cards based on a table that matches the database set up within the program. It will help with making an actual inventory rather than adding each card individually.

### API Implementation
There will be an API to fetch images of cards, as well as printing variations based on what you search. This will help with overall look of the card, and will give the program more sorting functionality to be able to find cards better. Say for Pokemon; You can search for just Supporters. Or in MTG you can search for just Lands/Creatures. This will make sorting through a large database that much quicker. There is also a functionality where we can fetch the average market price of cards to get total inventory data, or a all-in-one tracker/pricing program.

### Locally Ran
The best thing about it is that it is completely free to run, because it doesn't require any hosting. We can edit and save the local database of what we have directly to the computer that it is being ran on. Keeping all total inventory data safe and secure, as well as keeping initialization times low.
